# Zejun Bai — AI Engineering Portfolio

Public portfolio: https://baze-bai.github.io/

A static portfolio covering AI systems, applied ML / DL, and research. It contains 15 selected experience groups and links to their 20 named project members, with upstream research attributed separately.

## Website files

- `index.html`: portfolio layout and public contact information
- `app.js`: project filters and detail dialogs
- `styles.css`: responsive presentation
- `projects.json`: public project descriptions and repository links
- `Zejun_Bai_AI_Engineer_Resume.pdf`: public résumé
- `.nojekyll`: publish the static assets without Jekyll processing

GitHub Pages publishes the root of the `main` branch. Updates to the website files on that branch trigger a new deployment.
